B & W

黑白畫面 ＝ 抑鬱時嘅世界

抑鬱嘅時候，世界好似冇晒色彩。RAM 同源代碼慢慢修好，顏色就會一點一點返嚟。

今日少少色彩都算數。

Battery

電量 ＝ 個人能量

食飯、去廁所、沖涼都要用能量。抑鬱嘅時候，連呢啲基本嘢都好花力，呢個係症狀，唔係懶。

能量低就只做最基本嘅，做到已經好叻。

Temp

溫度 ＝ 情緒

情緒太熱，人會好難諗嘢、好難改變。按醫生指示食藥、做運動、食好食嘅嘢、瞓覺、靜觀、吐苦水，都可以幫情緒降溫。

先降溫，再做其他嘢。精神科藥物要跟醫生指示，唔好自行停藥或者加減。

RAM

RAM ＝ 運算能力

每刪除一個念頭或者舊習慣，腦袋就多返啲空間。一開始係零，好正常。情緒穩定、又有電，先刪得走。

RAM 未夠 10%，會食唔落、便秘、失眠；去到 30%，先有力見朋友同做運動；去到 50%，先可以開始修復源代碼。

身體同社交嘅改變，往往跟住腦袋嘅空間慢慢返嚟。

Work

工作／讀書 ＝ 會燒 RAM 又燒電

返工、返學要用好多專注力同能量。抑鬱嘅時候，做完會特別攰，係正常嘅。

撐唔住可以請假，同醫生傾吓病假或者調整工作量都得。

Pop-up

念頭視窗 ＝ 自動思想

佢哋用溫和、正面嘅字眼出現，例如「我要負起所有責任」「我應該快啲好返」，聽落好似好有道理，但其實係壓力。有啲念頭好頑固，要刪幾次先走。

認得佢係一個念頭，然後放低佢；放唔低就再嚟。

Scan

深度掃描 ＝ 認知行為治療（CBT）

CBT 係研究最多嘅抑鬱心理治療之一。三步：認出思考陷阱、搵唔支持佢嘅事實、換一個平衡啲嘅講法。

唔使一次掃晒，每日一兩個就夠。

Auto

自動程序 ＝ 慣性習慣

自我批評、討好別人、無限碌手機呢類習慣，唔使諗就自動運行，慢慢食晒運算能力。

每次揀一個，試一個細小嘅替代做法。佢裝返都好正常，再刪就得。

Source

源代碼 ＝ 思維入面嘅舊模式

好多舊模式喺以前嘅經驗寫成，例如「我要完美先值得被愛」。當時可能保護過你，但而家已經唔再適用，變成 bug。

RAM 去到 50%，就可以開始寫新版本。

Counsel

見輔導 ＝ 陪你搵 bug

由第一日起就可以見輔導。輔導唔係話你知你錯，而係陪你搵返啲舊模式。好多治療都係先穩定情緒，再處理深層嘅問題，所以 RAM 去到 50%，先開始修補。

搵唔到 bug 都唔緊要，傾過已經係進步。

Env

運行環境 ＝ 你身處嘅環境

如果仍然身處持續衝突、欺凌或者高壓嘅環境，佢會喺背景不停耗電。咁唔係你嘅錯。

預多啲充電同支援；可以搵社工或者熱線傾吓點樣改善環境。

Leak

漏電 ＝ 誘因同退步

失眠、壞消息、壓力，甚至無緣無故。復元唔係一條直線，有起有落係正常。

退步嗰日，用返最基本嘅工具：散熱、充電、瞓覺。

No boot

開唔到機 ＝ 好差嘅日子

有啲日子連起身都好難。部機冇壞，只係需要時間。

唔使掉咗部機。今日只做最基本嘅，保持耐心。

Reboot

最後順返 ＝ 復元係可能嘅

抑鬱症係可以治療嘅。好多人經過一段時間、適當支援同耐性，都會慢慢好返。遊戲最多十日就會順返；現實可能慢好多，但只要繼續，方向都係一樣。

記住呢條曲線：中間會跌，但整體向上。

想陪伴身邊人？

  • 聽多過講。「我喺度」比任何建議更有用。
  • 避免講「諗開啲」或者「人哋仲慘過你」。佢唔係唔想諗開。
  • 陪佢做細事：散步、食飯、陪佢去睇醫生。
  • 鼓勵佢搵專業幫助，亦記得照顧好你自己。

幾時應該搵專業人士？

如果情緒低落、對事情提唔起興趣、失眠或者疲倦持續兩個星期以上，或者已經影響工作、學業或人際關係，可以考慮搵家庭醫生、精神科醫生、臨床心理學家或者社工傾吓。如果有傷害自己嘅念頭，請即刻聯絡「求助」頁嘅熱線。
